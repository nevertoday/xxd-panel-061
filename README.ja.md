# 🦁 XXD Panel 061

### 写真を散在してエコーする視覚的記憶の断片に再編成する

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 061 は、写真から最も意味のある主題、行動、環境に関するヒントや比喩を約 3 ～ 6 つ選択し、切り紙、ガッシュ、パウダーワックス、リソグラフ、スクリーン印刷のグラフィック言語を使用して、それらを軽い個人的なビジュアル日記のページに整理します。

**キーワード:** 選択的記憶 · 複数断片の物語 · 切り絵のカラーブロック · 癒しのカラーパレット · 即興編集とレイアウト

## 使用する

```text
/xxd-panel-061 photo.jpg --mode design-only --size 3:4 --text prompt --locale ja-JP
```

単一の画像または画像ディレクトリ、上下の比較、左右の比較、純粋なデザイン描画、4 つの端の壁紙、マルチプロポーション、正確なピクセル、および 3 つのテキスト モードをサポートします。完全な動作については、[SKILL.md](SKILL.md) を参照してください。
