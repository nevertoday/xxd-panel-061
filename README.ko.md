# 🦁 XXD Panel 061

### 사진을 흩어지고 울리는 시각적 기억 조각으로 재구성합니다.

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 061는 사진에서 가장 의미 있는 주제, 행동, 환경 단서 또는 은유 중 약 3~6개를 선택하고 페이퍼 커팅, 구아슈, 파우더 왁스, 리소그래프 및 스크린 프린팅 그래픽 언어를 사용하여 이를 가벼운 개인 시각적 일기의 한 페이지로 정리합니다.

**키워드:** 선택적 기억 · 다중 조각 내러티브 · 종이 컷 컬러 블록 · 힐링 컬러 팔레트 · 즉석 편집 및 레이아웃

## 사용

```text
/xxd-panel-061 photo.jpg --mode design-only --size 3:4 --text prompt --locale ko-KR
```

단일 그림 또는 그림 디렉토리, 상단 및 하단 비교, 왼쪽 및 오른쪽 비교, 순수 디자인 그리기, 4엔드 배경화면, 다중 비율, 정확한 픽셀 및 3가지 텍스트 모드를 지원합니다. 전체 동작은 [SKILL.md](SKILL.md)를 참조하세요.
